# 🎮 Obstacle Course Game

**My first game built with Unreal Engine 5.6**

A small obstacle-course game created as my first hands-on project with **Unreal Engine 5.6**. The project focuses on learning the fundamentals of game development, including player movement, level design, obstacles, interactions, and Unreal Engine's Blueprint system.

## 🕹️ About the Game

The goal is simple: **reach the end of the obstacle course without falling or getting eliminated.**

The course contains different obstacles and challenges designed to test movement, timing, and control.

This project is primarily a **learning project** and serves as my starting point for developing games with Unreal Engine.

## 🛠️ Built With

* **Unreal Engine 5.6**
* **Blueprints**
* **C++**
* **Git & GitHub**

## ✨ Features

* Third-person player movement
* Obstacle-course gameplay
* Platforming and traversal challenges
* Basic level design
* Collision and physics interactions
* Unreal Engine based gameplay systems

## 📚 What I Learned

While developing this project, I worked with:

* Unreal Engine's editor and project structure
* Character and player movement
* Blueprint scripting
* Collision detection
* Level and environment design
* Gameplay logic
* Basic Unreal Engine debugging
* Using Git and GitHub to manage a game project
